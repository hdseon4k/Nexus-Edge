# 물류창고 바코드 매핑 시스템 의사결정 보고서 (A5 / NotebookLM 맞춤형)

> **문서 목적**: A5 출력 및 NotebookLM 슬라이드 4장 자동 생성을 위해 핵심만 극도로 압축 정리된 보고서.

---

## [Slide 1] Setup A: 기동성 위주 웨어러블 셋업 (작업자 도보용)

* **개요**: 작업자 착용형 세팅 (인프라 설치 무, 좁은 통로 및 예외 구역 전용)
* **핵심 스펙**:
  * **카메라**: 1/1.3인치 대형 센서 액션캠 (수광력 우수, 모션블러 억제)
  * **연산 장치**: 플래그십 모바일 AP (스마트폰 형태)
  * **마운트/모니터링**: 산업용 어깨 마운트 / 10.9인치 태블릿 (LTE 라우터 권장)
* **운영 환경**: 0°C ~ 35°C (모바일 AP 발열 스로틀링 & 배터리 한계로 극저온/고온 취약)
* **네트워크**: 엔터프라이즈급 Wi-Fi 6/7 필수 (고화질 무선 영상 스트리밍)
* **확장 한계**: **10대 미만** (Wi-Fi 트래픽 병목 발생)
* **평균공급가액(제경비일체)**: 대당 약 870만 원
* **의사결정 평가**:
  * **장점**: 초기 도입비 최소, 즉시 투입 가능
  * **단점**: 걸음걸이 오차 발생, 고가 Wi-Fi 인프라 공사 필수

---

## [Slide 2] Setup B: 베이스 스테이션 원거리 셋업 (고화질 정밀 탐지용)

* **개요**: 서버급 고성능 세팅 (최고 바코드 인식률, 앙상블 딥러닝 모델 구동)
* **핵심 스펙**:
  * **카메라/렌즈**: APS-C 적층형(Stacked) BSI 센서 (롤링셔터 왜곡 제로) + 고해상도 표준 렌즈
  * **전송/캡처**: 전용 무선 RF 송수신기 + 12G-SDI 캡처 인터페이스
  * **연산/모니터링**: 하이엔드 GPU 탑재 워크스테이션 + 5인치 필드 모니터 + 10.9인치 태블릿
* **운영 환경**: -10°C ~ 40°C (지게차 카메라단 기준 / 서버는 상온 유지)
* **네트워크**: 별도 구축 불필요 (독자 RF 무선망 생성, 인터넷 공사비 0원)
* **확장 한계**: **최대 4세트** (동일 공간 내 RF 주파수 채널 고갈 및 전파 간섭)
* **평균공급가액(제경비일체)**: 대당 약 3,660만 원
* **의사결정 평가**:
  * **장점**: 압도적 광학/인식 성능, 네트워크 구축비 0원
  * **단점**: 높은 기기 단가, 4대 초과 대규모 확장 물리적 불가능

## [Slide 3] Setup C: 온디바이스 엣지 AI 셋업 (대규모 상용화 타겟) 🌟

* **개요**: 지게차 거치형 엣지 연산 세팅 (네트워크 부하 제로, 최종 상용화 목표)
* **핵심 스펙**:
  * **카메라/렌즈**: M4/3 듀얼 네이티브 ISO 저조도 센서 + 방진방적 표준 렌즈
  * **제어/인터페이스**: 산업용 3축 짐벌 + 4K 캡처 링크
  * **연산/모니터링**: Nexus Edge (저전력 NPU 포함) + 10.9인치 태블릿
* **운영 환경**: -10°C ~ 40°C (**방진·방적·방한 완벽 지원**, 영하 10도 냉동창고 & 혹서기 야드 대응)
* **네트워크**: 저가형 LTE 라우터 또는 일반 Wi-Fi (수 KB 텍스트 메타데이터만 전송)
* **확장 한계**: **무제한** (네트워크 부하 0, 수백 대 동시 운영)
* **평균공급가액(제경비일체)**: 대당 약 1,845만 원
* **의사결정 평가**:
  * **장점**: 대규모 확장 무제한, 전천후 환경 대응, 네트워크 공사비 0원
  * **단점**: 지게차 전원/거치 초기 세팅 공수 필요

## [Slide 4] 3,200평 인프라 투자비용(TCO) 비교 및 최종 의사결정

### 📊 통신 인프라 구축 비교표 (창고 2,500평 + 야드 700평)

| 비교 항목 | 기존 방식 (Enterprise Wi-Fi 6/7) | 혁신 방식 (Setup C + 개별 LTE 라우터) |
| :--- | :--- | :--- |
| **대상 셋업** | Setup A, Setup B (대규모 구축 시) | **Setup C (온디바이스 엣지 AI)** |
| **전송 데이터** | 무거운 무선 영상 원본 (수십 Mbps) | **가벼운 텍스트 메타데이터 (수 KB)** |
| **필요 인프라** | AP 30~60대 + PoE 스위치 장비 | 지게차/태블릿당 산업용 USB LTE 동글 |
| **포설 공사** | 천장/야드 유선 랜(UTP) 배선 공사 필수 | **공사 없음 (0원)** |
| **초기 구축비(CAPEX)** | **약 1,400만 ~ 2,200만 원** | **0원 (초기 공사비 완벽 소거)** |
| **연간 유지비(OPEX)** | AP 주기적 점검 및 무선 환경 관리 | **대당 연 약 6.6만 원 (월 5,500원)** |
| **야외 야드 로밍** | 야드 전용 AP 추가 설치 (음영 위험) | **전국 통신사 기지국 무제한 로밍** |
| **시스템 확장성** | AP 주파수 정체로 확장 한계 | **수백 대 동시 운영 무제한** |

### 🎯 최종 의사결정 제안
1. **PoC (개념 증명 시연)**: 소규모(1~2대) 시연은 압도적 인식률의 **Setup B**로 진행하여 성능 입증.
2. **B2B 본사업 (대규모 납품)**: 초기 공사비 0원 및 무한 확장이 가능한 **Setup C (엣지 AI + LTE)**로 최종 운영 체계 확정.
