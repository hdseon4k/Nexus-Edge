## 2. 🎯 최종 목표가 'Setup C'가 되어야만 하는 현실적 이유

연구실 데모에서는 가장 성능이 좋은 Setup B가 훌륭해 보일 수 있으나, 실제 물류/유통 기업을 대상으로 한 **수십~수백 대 규모의 상용화 납품 시에는 오직 Setup C만이 유일한 해답**입니다. 그 이유는 다음과 같습니다.

### 1. 인프라 구축 비용의 폭발적 절감 (네트워크 확장성)
*   **Setup B의 함정**: 카메라의 고화질 비압축(또는 약압축) 영상을 서버로 무선 전송하려면, 창고 내에 초고가의 기업용 Wi-Fi 6/7 AP망이나 5G 특화망(Private 5G)을 촘촘히 깔아야 합니다. 지게차가 20대만 넘어가도 공유기가 영상 트래픽을 버티지 못하고 다운됩니다. 이는 고객사에게 배보다 배꼽(통신망 구축비)이 더 커지는 결과를 초래합니다.
*   **Setup C의 해결책**: 영상 처리는 지게차에 달린 미니 PC(M90q)와 NPU(Hailo)가 **현장에서 끝냅니다.** 그리고 중앙 서버(대시보드)로는 "현재 바코드 번호 1234가 창고의 X:10, Y:5 위치에 있다"라는 텍스트 한 줄(수십 바이트)만 무선으로 보냅니다. 고객사 창고에 이미 설치되어 있는 낡고 저렴한 공유기(Wi-Fi 4/5)나 심지어 LTE 동글 하나만으로도 지게차 수백 대를 동시에 굴릴 수 있습니다.

### 2. 서버 운영 유지보수 비용 (TCO 절감)
*   Setup B 방식으로 50대의 지게차 영상을 중앙에서 한 번에 처리하려면, 중앙 서버룸에 RTX 5090 수십 장을 꽂은 초고가 데이터센터급 서버렉을 구축하고 에어컨을 빵빵하게 틀어야 합니다. 
*   Setup C는 연산력을 지게차(M90q) 50대에 분산시켜 버리므로, 중앙 서버는 그저 텍스트 데이터만 받아 DB에 저장하고 2D 웹 지도를 뿌려주는 가벼운 클라우드 서버(AWS EC2 저렴한 인스턴스) 하나면 충분합니다. 

### 3. 통신 장애 대처 (Shadow Zone)
*   거대한 철제 랙이 겹겹이 쌓인 물류 창고는 전파 음영 지역(Wi-Fi가 안 터지는 곳)이 무조건 존재합니다.
*   **Setup B**는 통신이 끊기는 순간 AI 연산 서버와 연결이 끊겨 그 구역의 재고 데이터가 통째로 날아갑니다.
*   **Setup C**는 통신이 잠시 끊겨도 엣지(M90q)에서 자체적으로 바코드를 인식하고 로컬에 저장해 둡니다. 지게차가 통신 음영 지역을 빠져나와 Wi-Fi에 다시 연결되는 순간, 저장해 둔 텍스트 좌표 묶음을 서버로 일괄 전송(Sync)하면 데이터 유실이 0%가 됩니다.

### 4. B2B 단가와 도입 저항 최소화
*   Setup B는 1세트 도입에 약 3,660만 원으로 고객사의 도입 장벽이 매우 높습니다.
*   Setup C는 1세트당 약 1,700만 원이며, 창고 서버나 네트워크 공사 비용이 추가로 들지 않기 때문에 영업 시 ROI(투자 대비 수익률)를 고객에게 설득하기가 압도적으로 유리합니다.

## 3. 🌐 3,200평 규모 통신 인프라 셋업 상세 비교표 (Wi-Fi vs LTE)

창고 2,500평 및 야외(야드) 700평, 총 3,200평 규모에 아키텍처를 도입할 때 적용 가능한 두 가지 통신 네트워크 인프라 옵션 비용 비교입니다. 텍스트(메타데이터)만 전송하는 **Setup C(온디바이스 엣지 AI)**와 결합 시 LTE 도입이 압도적으로 유리함을 보여줍니다.

### 📊 옵션 1: Enterprise Wi-Fi Mesh 구축 (전통적 방식)
*   **AP 수량 산정**: 창고 내부 100평당 1대(25대) + 개방형 야드 140평당 1대(5대) = **총 30대**
*   **필수 부대장비/공사**: 30대의 AP에 전력을 공급할 **PoE 스위치 장비** 및 천장/야드까지 이어지는 대규모 **유선 랜(UTP) 배선 공사가 필수적으로 동반**됩니다.

창고에 거대한 Wi-Fi 망을 까는 대신 **지게차 1대당 1개의 LTE 모뎀**만 장착합니다.
