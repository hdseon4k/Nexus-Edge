# 🚀 2차 현장 실증 계획서 (Phase 2: Real-time Live POC)

본 계획서는 1차 실증에서 수집한 데이터를 바탕으로 **실내 위치 추적(SLAM)과 AI 객체 탐지 모듈 개발을 완료한 후, 현장에 다시 방문하여 실시간(Live)으로 시스템이 동작하는지 검증**하기 위한 가이드입니다.

## 🎯 2차 실증 목표
1. **소프트웨어 통합 검증**: 카메라 영상 수신 -> 렌즈 왜곡 보정 -> 실시간 SLAM -> 바코드 디코딩 -> 3D 좌표 변환 파이프라인이 지연 없이 동작하는가?
2. **On-Device Edge AI 실증 (Setup C)**: 고가의 Wi-Fi 인프라 없이, Hailo NPU를 활용하여 메타데이터(수 KB)만 전송해도 실시간 2D 맵 상에 바코드 재고가 그려지는가?
3. **VIO (센서 퓨전) 검증**: 특징점이 없는 갈색 박스 구간에서도 IMU 데이터 결합을 통해 카메라 위치(궤적)가 튀지 않는가?

---

## 💻 현장 구동 소프트웨어 (미리 개발되어야 할 항목)
2차 실증을 나가기 전, 랩실에서 다음 기능들이 완성되어 랩탑(ThinkPad) 및 미니PC(M90q)에 설치되어야 합니다.

1. **카메라 입력 어댑터 (`stream_manager.py`)**
   - Insta360 체커보드 영상으로 도출한 `카메라 내부 파라미터(Intrinsic)`를 적용한 실시간 왜곡 보정(Undistort) 로직.
   - 5G/Wi-Fi 모바일 허브(S24) 스트림 수신 및 로컬 USB/SDI 캡처 기능.
2. **실시간 하이브리드 SLAM (`aruco_slam.py` / `visual_slam.py`)**
   - 사전에 측정한 `marker_map.json`을 로드하여 ArUco 마커가 보일 때마다 절대 좌표를 즉시 리셋(Loop Closure)하는 로직.
3. **YOLO + ZBar 앙상블 탐지 (`detector.py`)**
   - 1차 수집 데이터로 파인튜닝된 YOLOv11 모델 탑재.
   - HailoRT 컴파일을 마친 `.hef` 포맷 모델 구동 (M90q용).
   - Ray Casting을 이용한 절대 깊이(Depth) 및 바코드 3D 위치 산출 로직.
4. **WebSocket 기반 대시보드 (`app.py`, `map_ui.html`)**
   - 태블릿 접속용 웹 서버 구동 및 2D Canvas 실시간 궤적 렌더링.

## 🏁 2차 실증 수행 시나리오
1. **장비 부팅 및 연결**: 카트(또는 작업자)에 장비를 세팅하고, 카메라와 랩탑(또는 M90q)을 연결합니다.
2. **시스템 Initialize**: 초기 위치(시작점)에 있는 ArUco 마커를 카메라에 비추어 SLAM의 0점(X:0, Y:0)을 잡습니다.
3. **주행 테스트**: 창고를 주행하며 실시간으로 태블릿(Lenovo Tab) 화면의 2D 웹 맵을 모니터링합니다.
4. **결과 확인**: 내가 걸어간 궤적이 선으로 그려지고, 선반에 있던 박스들의 바코드 ID가 정확한 위치에 점으로 찍히는지 확인합니다.
